# 라운드 입력 신뢰도와 보상 심사 기준

적용 시작: 2026-10-15. **이 문서의 시간 기준은 샷 기록 저장을 제한하지 않는다.** 현재 포인트 지급은 비활성이다.

## 서버가 확인하는 자료

- 라운드 첫 서버 생성 시각과 완료 시각을 서버에서 고정한다. 브라우저가 해당 값을 바꾸려 해도 DB 트리거가 원래 값으로 돌린다.
- 샷 추가·수정·삭제와 완료 후 홀 수정의 **서버 수신 시각**을 별도 추가 전용 이력에 남긴다. 사용자가 샷을 수정하거나 직전 샷을 복원할 수 있는 기능은 유지한다.
- 사용자는 시작 전에 `라운드 중 입력` 또는 `지난 라운드 입력`을 고른다. 일괄 퍼트도 입력 방식으로 구분한다. 이 선택은 이용자 진술이며 그 자체가 현장 증빙은 아니다.
- 구버전 라운드에는 새 서버 이력이 없으므로 `자가 기록`으로 표시한다. 기존 생성 시각만으로 현장 기록으로 소급 판정하지 않는다.

## 극최소 소요시간

| 홀 수 | 필드 | 스크린 |
| ---: | ---: | ---: |
| 6홀 | 40분 | 8분 |
| 9홀 | 60분 | 12분 |
| 12홀 | 80분 | 16분 |
| 18홀 | 120분 | 24분 |

계산식은 필드 `홀 수 × 400초`, 스크린 `홀 수 × 80초`다. 일반적인 플레이 시간의 추정값이 아니라 **극단적인 단시간 입력을 가리는 최저선**이다. 실제 라운드 중 입력을 시작한 시점부터 서버가 완료를 받은 시점까지 비교한다. 사후 입력, 오프라인 기록 재전송, 네트워크 오류는 짧게 관측될 수 있어 기록을 버리지 않고 확인 상태로 분류한다.

## MY의 확인 상태

- `소요시간 기준 통과 · 현장 미확인`: 서버 관측 시간이 최저선 이상이며 홀·샷 이력이 있다. 실제 플레이 증명이나 포인트 지급 승인은 아니다.
- `기록 확인 필요`: 최저선 미달, 1분 안에 12개 이상 샷 추가, 또는 완료 후 수정이 확인되었다. 자동 제재나 기록 삭제를 하지 않는다.
- `자가 기록`: 지난 라운드 입력, 새 이력이 없는 과거 기록, 또는 홀·샷 이력 부족.
- `기록 진행 중`: 아직 완료 전.

포인트 지급 기능을 열 때는 서버가 이 상태와 구매·환불·추천 이력을 함께 확인해야 한다. **시간 통과만으로 금전성 포인트를 자동 지급해서는 안 된다.** 이상 신호가 있는 경우 이용자에게 사유와 재확인 방법을 제공하고, 사람이 확인할 수 있는 보류 상태로 둔다.

## 위치·현장·기기 확인의 다음 단계

- 현재 골프장 카탈로그에는 검증된 구장 경계/중심 좌표가 없다. 지역명이나 주소만으로 GPS를 비교하면 실제 구장 밖의 인접 시설을 구분하기 어렵다. 따라서 **현재 위치정보는 수집하지 않는다.**
- 구장별 좌표와 오차 반경을 검수한 뒤 필드에서만 별도 선택 안내를 거쳐 시작·중간·종료 점검을 추가한다. 정확도 불량, 권한 거부, 오프라인 상태는 자가 기록으로 남길 수 있게 한다. 원시 이동 경로는 저장하지 않는 방향을 권장한다.
- 스크린은 GPS 대신 제휴 시설의 일회성 현장 코드나 예약/결제 확인 연동을 우선한다. 정적인 QR 이미지나 임의 사진만으로는 높은 확인 등급을 부여하지 않는다.
- 향후 전용 모바일 앱이 생기면 Android Play Integrity/iOS App Attest를 보상 요청에 붙일 수 있다. 현재 웹 앱에는 해당 네이티브 검증을 적용하지 않는다.

개인정보 안내는 서버 입력·수정 시각과 신뢰도 평가 목적을 고지하도록 갱신했다. 위치정보를 수집하기 전에 별도 목적·항목·보유기간·권한 안내와 관계 법령 검토가 필요하다.
