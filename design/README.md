# 앱 아이콘 원본

`app-icon-source.png`는 앱 아이콘의 원본 그림(1024×1024)이다. 둥근 모서리 바깥은 잘라 내 사방이 초록으로 꽉 차 있다.
휴대폰이 모양(둥근 사각형, 원)을 직접 잘라 내므로 그림에는 모서리를 넣지 않는다.

이 원본으로 만든 파일:

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `public/icons/icon-192.png`, `icon-512.png` | 192, 512 | 홈 화면 앱 아이콘(manifest) |
| `public/icons/icon-maskable-512.png` | 512 | 원형 등으로 잘리는 안드로이드 아이콘. 그림을 80%로 줄이고 가장자리 색을 이어 여백을 채웠다 |
| `app/apple-icon.png` | 180 | iPhone 홈 화면 |
| `app/icon.png` | 64 | 브라우저 탭 |

아이콘을 바꿀 때는 위 파일을 모두 새 그림으로 다시 만든다.
